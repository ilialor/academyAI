# AcademyOpenAI

## Обзор проекта

AcademyOpenAI - это платформа для быстрого преобразования англоязычного образовательного контента (видео/текст) в интерактивные русскоязычные курсы с использованием современных технологий искусственного интеллекта.

### Видение и цели

**Видение:** Стать ведущей платформой для быстрого преобразования англоязычного образовательного контента в увлекательные, интерактивные русскоязычные курсы.

**Цель:** Создать надежную, масштабируемую, контейнеризированную платформу, использующую современные технологии ИИ и бэкенда для автоматизированной генерации курсов, доступных через веб и мобильные приложения.

## Ключевые возможности

- **Мультимодальный ввод:** Принимает английские видеофайлы и текстовый контент
- **ИИ-преобразование:** Использует современные модели для транскрипции, перевода и генерации интерактивного контента
- **Автоматическое структурирование курса:** Генерирует логические модули/уроки из исходного материала
- **Богатая интерактивность:** Встраивает тесты (MCQ, T/F), вопросы для размышления, определения ключевых слов и резюме
- **Ролевой доступ:** Различные интерфейсы и возможности для Студентов, Преподавателей и Администраторов
- **Кросс-платформенный доступ:** Бесперебойная работа через Веб (React) и Мобильные (React Native) приложения
- **Масштабируемая архитектура:** Контейнеризированные микросервисы, разработанные для роста

## Архитектура системы

AcademyOpenAI построен на микросервисной архитектуре, состоящей из следующих основных компонентов:

- **Фронтенд:** React (веб) и React Native (мобильный)
- **API Gateway:** Kong для маршрутизации и безопасности
- **Сервисы:**
  - Auth & Profile Service (FastAPI)
  - Courses Service (FastAPI)
  - Pipeline Worker (Async - Celery/FastStream)
- **Базы данных:**
  - PostgreSQL (для аутентификации и профилей)
  - MongoDB (для курсов и контента)

Подробная информация об архитектуре доступна в [документации по архитектуре](AcademyOpenAI\docs\architecture.md).

## Установка и запуск

### Требования

- Docker и Docker Compose
- Git

### Локальная разработка

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/ilialor/academyAI.git
   cd AcademyOpenAI
   ```

2. Запустить с помощью Docker Compose:
   ```bash
   docker-compose --profile all up -d
   ```

3. Доступ к сервисам:
   <!-- - Веб-интерфейс: http://localhost:3000
   - API Gateway: http://localhost:8000
   - Документация API: http://localhost:8000/docs -->
